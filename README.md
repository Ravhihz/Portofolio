# ✨ Ravhi Hz — Portfolio

> A living showcase of real projects. No filler, just work.

---

## 🎯 What's Here?

**Live Projects** | Real GitHub repositories, real data. Not static cards—this portfolio fetches and displays your actual work via GitHub REST API.

**Flagship Project** | [Captionin](https://github.com/Ravhihz/Captionin) — your standout project, featured as a hero card.

**Interactive Experience** | Terminal-style hero with typing effects, scroll-reveal animations, and an editor-like tab navigation that syncs with your viewport.

---

## 🛠 Built With

```
TypeScript 93.8% | CSS 4.1% | JavaScript 2.1%
```

- **Next.js 16** (App Router) — fast, server-optimized
- **Tailwind CSS v4** — utility-first design
- **lucide-react** — clean icon system
- **GitHub REST API** — live project data, cached hourly

---

## 🔍 Key Features

✅ **Auto-fetching projects** — data stays fresh without manual updates  
✅ **Smart caching** — Next.js revalidation keeps load times snappy  
✅ **Responsive design** — beautiful on mobile, desktop, and everything between  
✅ **Scroll-aware navigation** — tabs update as you scroll through sections  
✅ **Smooth animations** — reveal effects that don't distract, just enhance
